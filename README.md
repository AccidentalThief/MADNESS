# Madness

Madness is a local co-op multiplayer party game built in Unity. Players compete in a series of minigames to decide who wins.

## Competition

Madness placed **4th** in the TSA Video Game Design Competition.

## Tech Stack

- Unity 3D
- C#
- Git and GitHub

## Core Features

- **State management** to coordinate game flow.
- **Teammate minigame integration** to bring individual minigames together into a party-game experience.
- **Local co-op mechanics** for players competing on the same system.

## Repository History

This repository has a single commit because development was initially done locally during a rapid-prototyping period with tight deadlines. The project was pushed to GitHub afterward.

## Clone and Run Locally

1. Install [Unity Hub](https://unity.com/download) and a Unity Editor version that supports the project.
2. Clone the repository:

   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

3. In Unity Hub, select **Add** and choose the cloned project folder.
4. Check `ProjectSettings/ProjectVersion.txt` for the Unity Editor version used by the project. Install that version if needed, then open the project.
5. Open the game's main scene in the Unity Editor.
6. Press **Play** to run the game locally.
